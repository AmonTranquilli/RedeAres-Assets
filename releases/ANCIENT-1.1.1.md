# Rede Ares — Ancient 1.1.1

Adiciona a moldura Ancient ao menu real de `/ranks` (`AresLevel`, Ranks do Império), com aberturas para os 15 títulos, o perfil do jogador e o botão de fechar. O título azul centralizado e os demais menus de 1.1.0 são preservados.

SHA-1: `a005f9810a9ce715efab308306447a62ea8e39fc`.

Compatível com Minecraft Java 1.21.11. Preserva os 56 recursos anteriores. Arte Ancient de NitroSetups fornecida pelo proprietário do servidor; o ZIP contém apenas as interfaces montadas.
