# Rede Ares — Ancient 1.1.0

Centraliza os títulos das 12 telas Ancient e o rótulo do inventário. Títulos dos demais menus virtuais do Rankup recebem gradiente azul centralizado por AresMenus 1.1.0, sem alterar os títulos usados pelos plugins para processar cliques.

SHA-1: `72233c3d2625c42fdaf88ec2cdbe5bc1c3a1b100`.

Compatível com Minecraft Java 1.21.11. Preserva byte a byte os 56 recursos do pacote anterior. Arte Ancient de NitroSetups fornecida pelo proprietário do servidor; este ZIP inclui somente interfaces montadas.
