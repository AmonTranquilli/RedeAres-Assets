# RedeAres Assets

Arquivos públicos da Rede Ares para distribuição aos jogadores.

## Mina Privada UI

O resource pack inicial está em `releases/RedeAres-Mina-UI-1.1.zip`.

Ele exige Minecraft Java 1.21.11 e Paper compatível. Use o SHA-1 publicado junto ao arquivo na configuração `resource-pack-sha1` do servidor.
