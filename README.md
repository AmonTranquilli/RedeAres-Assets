# RedeAres Assets

Arquivos públicos da Rede Ares para distribuição aos jogadores.

## Mina Privada UI

A versão atual é `releases/RedeAres-Mina-UI-1.2.zip`.

Ela traz o painel claro da Mina Privada, remove os vidros de preenchimento e inclui os ícones personalizados. Exige Minecraft Java 1.21.11 e Paper compatível. Configure o SHA-1 correspondente em `resource-pack-sha1` no servidor.
