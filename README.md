# RedeAres Assets

Arquivos públicos da Rede Ares para distribuição aos jogadores.

## Mina Imperial 3.2

Pacote atual: `releases/RedeAres-Mina-Imperial-3.2.zip`.

Painel redesenhado em pixels nativos, com seis linhas, placa de título elevada, botões em relevo e rótulos no tamanho padrão da fonte do Minecraft. Os rótulos são componentes de fonte separados do fundo; a arte não é uma imagem grande reduzida.

Minecraft Java 1.21.11. SHA-1: `7b5a128002e4c138e3d10f6272f8bc631f30d0e3`.

Requer AresPrivateMines correspondente. Não sobrescreve recursos globais do Minecraft. A renderização final precisa de conferência no cliente.
