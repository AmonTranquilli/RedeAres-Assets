# RedeAres Assets

Arquivos públicos da Rede Ares para distribuição aos jogadores.

## Mina Privada UI

A versão atual é `releases/RedeAres-Mina-UI-2.2.zip`.

Essa versão desenha os três cards diretamente no fundo exclusivo de uma janela Shulker da Mina Privada. Isso mantém os baús comuns intactos e é compatível com Minecraft Java 1.21.11. Configure o SHA-1 correspondente em `resource-pack-sha1` no servidor.
