# RedeAres Assets

Arquivos públicos da Rede Ares para distribuição aos jogadores.

## Mina Privada UI

A versão atual é `releases/RedeAres-Mina-UI-1.3.zip`.

Ela traz o painel claro dourado do Rankup Império, remove os vidros de preenchimento e deixa títulos de qualquer menu de baú legíveis. Exige Minecraft Java 1.21.11 e Paper compatível. Configure o SHA-1 correspondente em `resource-pack-sha1` no servidor.
