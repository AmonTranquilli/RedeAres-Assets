# RedeAres Assets

Arquivos públicos da Rede Ares para distribuição aos jogadores.

## Mina Privada UI

A versão atual é `releases/RedeAres-Mina-UI-1.4.zip`.

Ela mantém os menus de baú genéricos no visual vanilla e aplica uma janela compacta dourada exclusiva à tela principal da Mina Privada. Exige Minecraft Java 1.21.11 e Paper compatível. Configure o SHA-1 correspondente em `resource-pack-sha1` no servidor.
